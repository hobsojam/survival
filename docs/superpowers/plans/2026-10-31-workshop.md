# The Workshop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a workshop on the east far ground, with three one-time upgrades. The saw doubles the wood from felling. The handcart catches felled wood in a cart that counts as stored wood. The bed tools let the vegetable beds go a day longer without water.

**Architecture:** A new module, `src/game/workshop.ts`, owns the three upgrades: their costs, one blocker, one `makeUpgrade` action, how much wood a felling gives, and where it goes. The cart is a new number, `GameState.cartWood`. The wood helpers in `src/game/wood.ts` count it, so builds, the campfire and the fireplace can all use it with no other changes. The bed tools only move the drying thresholds in `src/game/beds.ts`.

**Tech Stack:** TypeScript, Phaser 3 (code-drawn sprites), Vite, Vitest (node), oxlint.

**Spec:** `docs/superpowers/specs/2026-10-31-workshop-design.md`. The base design is `docs/superpowers/specs/2026-10-31-homestead-buildings-design.md`, Project 3.

**Branch:** `agent/workshop`, stacked on `agent/well-vegetable-beds` (PR #103). Open the PR against `agent/well-vegetable-beds`.

## Global Constraints

- Every task passes `npm test`, `npm run lint` and `npm run build` before committing.
- **Save version:** `SAVE_VERSION` goes from 22 to **23** in Task 1 and stays there. There are no migrations.
- **The workshop:** `BUILDINGS.workshop = { name: 'Workshop', description: 'Make a saw, a handcart and bed tools', symbol: '⚒', cost: { wood: 10, fiber: 4, stone: 6 }, prerequisite: 'toolshed', ground: 'east-far' }`. Spot offset **(8, -1)**, which is (28, 14). The cart parks at offset **(8, 1.5)**, which is (28, 16.5).
- **Upgrades** (`WORKSHOP_UPGRADES` in `src/game/workshop.ts`, in this order):
  - `saw`: name `'saw'`, cost `{ wood: 3, fiber: 0, stone: 3 }`
  - `handcart`: name `'handcart'`, cost `{ wood: 8, fiber: 2, stone: 1 }`
  - `bedTools`: name `'bed tools'`, cost `{ wood: 3, fiber: 1, stone: 1 }`. It also needs the vegetable beds.
- **Saw:** felling gives `BALANCE.sawWood = 4` wood instead of 2. This includes trees marked for clearing.
- **Handcart:** `BALANCE.handcartCapacity = 12`. Felled wood fills the cart first, then the bag.
- **Wood order:** wood is spent from the bag first, then the cart, then the woodpile and woodshed. The fireplace draws from the woodpile and woodshed first, then the cart.
- **Bed tools:** a crop withers at day 5 instead of 4. Dry soil (day 2) and stalling (day 3) are unchanged. *(Changed after the final review, by the user's choice: shifting every threshold let crops ripen unwatered.)*
- **Copy** is plain and warm, with no exclamation marks. **Art** is drawn in code in the existing palette, edged in dark wood so it reads against the camp's bare earth.

## Review Focus

1. **Felling with the saw when only part of the wood fits.** Felling is refused, nothing is chopped, and no wood is lost. Task 1 tests this without a cart. Task 2 tests it with the bag and cart together.
2. **A sleep through the night where the fireplace burns into the cart.** Once the woodpile and woodshed are empty, the fireplace keeps drawing from the cart. It doesn't go out while the cart still holds wood, and "The fireplace went out in the night." doesn't show. Task 2 pins this.
3. **Unloading into a nearly full store.** Only what fits moves, the rest stays in the cart, and the message says so. Task 2 pins this.
4. **Making the bed tools while a bed is on its third dry day.** The bed isn't withered, and on the next dry dawn it reaches day 4 and stalls instead of withering. Task 3 pins this.
5. **Old or tampered saves.** A save with `cartWood` above 12, `cartWood` set without the handcart, an upgrade made without the workshop, or bed tools without the beds is rejected. Tasks 1 to 3 each pin their own field.
