# The View from the Keep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Climbing the finished keep by day opens a painted, gently moving picture of the player's own land, which stays until they come down.

**Architecture:** Pure helpers decide what the camp shows, produce the picture as lists of rectangles on a 320×200 grid, and work out how it fits the frame. A thin Phaser layer paints those rectangles on a canvas texture above everything but the fade cover. `DoorFade` gains an open-ended hold for the view, and `GameScene` holds the clock and any notices until the player comes down.

**Tech Stack:** TypeScript, Phaser 3, Vite, Vitest, oxlint.

**Spec:** `docs/superpowers/specs/2026-11-06-keep-view-design.md`. The composition and palette to port are in `docs/art-review/keep-view/mockup.html`.

## Global Constraints

- No new dependencies and no image files. All art is drawn in code.
- No change to the saved shape. `SAVE_VERSION` stays 38.
- The picture has no labels, markers, buttons or tappable places. The only text is the season's line.
- It must never show a building the player hasn't built.
- SonarCloud needs 80% coverage on new code, and `App.ts` is untested, so logic goes in tested helpers.
- The README only gets the climb's description replaced, in **The keep**.

## Review Focus

- A phone is rotated while the picture is up: the picture still fills the frame and the camp stays in view.
- A key held from the door (E on auto-repeat) must not bring the player straight back down.
- Pausing over the picture, then resuming, returns to the picture, and a tap or key while paused doesn't come down.
- On a phone with a sheet open, the first tap closes the sheet and doesn't come down.
- Climbing just before nightfall: the 12 seconds may pass into night, but the picture still shows, and the player comes down into night with nothing lost.

### Task 2: The picture

**Files:**
- Create: `src/scene/keepViewArt.ts`
- Test: `tests/keepViewArt.test.ts`

**Interfaces:**
- Consumes: `CampView` from Task 1, `Season` from `src/game/calendar.ts`, `journalEntry` from `src/game/journalEntries.ts`.
- Produces:
  ```ts
  export const PICTURE_WIDTH = 320;
  export const PICTURE_HEIGHT = 200;
  export interface PictureRect { x: number; y: number; w: number; h: number; color: string }
  /** What doesn't move: sky, ridges, woods, cliff, hills, path, battlements and the camp's buildings. */
  export function stillRects(season: Season, camp: CampView): PictureRect[];
  /** What moves at this tick (8 ticks a second): clouds, smoke, sails, sheep, and falling snow, leaves or petals. */
  export function movingRects(season: Season, camp: CampView, tick: number): PictureRect[];
  export function viewLine(season: Season): string;
  export interface PictureFit { scale: number; x: number; y: number }
  export function pictureFit(viewWidth: number, viewHeight: number): PictureFit;
  ```

- [ ] **Step 1: Write the failing tests**

Build a `bare` `CampView` (Task 1's new-camp values) and a `full` one in the test file.

- `each season paints differently`: `stillRects` differs for all four seasons, with the same camp.
- `the same inputs always paint the same picture`: two `stillRects` calls are deep-equal, as are two `movingRects` calls at one tick. Noise must be seeded, not `Math.random`.
- `each landmark adds to the picture, and only around the camp`: `it.each` over each `CampView` field. Turning it on from `bare` changes `stillRects` or `movingRects` at tick 0, and every changed rect lies within x 85–155 and y 65–120. Compare by finding the rects not present in `bare`.
- `an unbuilt windmill turns nothing`: with `windmill` false, `movingRects` at ticks 0 and 5 contain no sail colour (export `SAIL_COLOR`). With it true, the sail rects differ between those ticks.
- `autumn orchard shows apples only on trees that have them`: adding `apples: true` adds rects of `APPLE_COLOR` (export it).
- `summer has nothing falling, and winter has the most`: count `movingRects` with `bare` across seasons, checking summer's is the lowest and winter's the highest.
- `viewLine uses the journal's words`: `viewLine('autumn')` is `From the top of the keep, the woods have all turned.`, and the same for the other three seasons with the spec's exact lines.
- `the picture fills every frame the game supports`: `it.each` over `[480,300], [640,480], [640,300], [195,339], [180,340], [320,568]`. `scale * 320 >= w`, `scale * 200 >= h`, `x <= 0`, `y <= 0`, `x + 320*scale >= w`, `y + 200*scale >= h`.
- `the camp stays in view at every one of those sizes`, including after rotating: `x + 85*scale >= 0`, `x + 155*scale <= w`, `y + 85*scale >= 0`, `y + 120*scale <= h`.
- `the battlements stay along the bottom`: `y + 200*scale` equals `h` at every size.
